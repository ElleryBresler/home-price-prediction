| `dim_property` | `gr_liv_area` | Ames Housing Dataset | Original `GrLivArea` column | Model feature: above-ground living area |
| `dim_property` | `bedroom_abvgr` | Ames Housing Dataset | Original `BedroomAbvGr` column | Model feature: above-ground bedrooms |
| `dim_property` | `full_bath` | Ames Housing Dataset | Original `FullBath` column | Model feature: full bathrooms above grade |
| `dim_property` | `year_built` | Ames Housing Dataset | Original `YearBuilt` column | Model feature: construction year |
| `dim_property` | `garage_cars` | Ames Housing Dataset | Original `GarageCars` column | Model feature: garage capacity |

| `dim_location` | `neighborhood` | Ames Housing Dataset | Original `Neighborhood` column | Model feature and geographic reporting |

## Fact Tables

| Table | Field | Comes from | How | Used for |
|---|---|---|---|---|
| `fact_economic_conditions` | `economic_id` | Generated by PostgreSQL | Automatically generated identity value | Primary key |
| `fact_economic_conditions` | `date_id` | Joined to `dim_date` | Matches the economic observation's month to `dim_date.date_id` | Foreign key; aligns economic data with sales periods |
| `fact_economic_conditions` | `mortgage_rate` | FRED API | Series `MORTGAGE30US`; 30-year fixed-rate mortgage observations aggregated to monthly averages | Potential model feature; aligns mortgage rates with home-sale periods |
| `fact_home_sale` | `sale_id` | Ames Housing Dataset | Original `Id` column | Primary key; identifies each sale record |
| `fact_home_sale` | `property_id` | Ames Housing Dataset | Original `Id` column, linked to `dim_property.property_id` | Foreign key |
| `fact_home_sale` | `location_id` | Ames Housing Dataset and database relationship | Neighborhood matched to `dim_location` | Foreign key; supports geographic features and reporting |
| `fact_home_sale` | `date_id` | Ames Housing Dataset and calculation | `YrSold` and `MoSold` converted to a year-month key | Foreign key; links the sale to its time period |
| `fact_home_sale` | `sale_price` | Ames Housing Dataset | Original `SalePrice` column | Target variable for the predictive model |

## Source Fields Used but Not Stored

- **Ames Housing Dataset:** `Id`, `Neighborhood`, `YrSold`, `MoSold`, `OverallQual`, `GrLivArea`, `BedroomAbvGr`, `FullBath`, `YearBuilt`, `GarageCars`, and `SalePrice` are mapped to fields in the database schema.
- Additional Ames fields remain in the original local `train.csv` but are not currently included in the database schema.
- **Census API:** The extraction script retrieves `NAME`, `B19013_001E`, `B01003_001E`, and `B15003_022E`, along with geographic identifiers. The demographic values represent Ames, Iowa, as a whole, not individual neighborhoods.
- **FRED API:** The extraction script retrieves observations for the `MORTGAGE30US` series. Observation dates and source metadata are retained in the raw JSON response. Inflation and unemployment series are outside the current project scope.

## Outstanding Validation

1. Census demographic measures represent Ames, Iowa, as a whole and cannot be interpreted as neighborhood-specific values. This limitation must be considered when building the model's feature table.
2. Mortgage-rate observations must be aligned appropriately with home-sale months.
3. Missing Census or economic observations must be evaluated and handled during the transformation stage.
4. The database schema and this data dictionary must remain synchronized as the project develops.
5. The project requires a joined machine-learning feature table before modeling. This will be developed in a later project stage.
